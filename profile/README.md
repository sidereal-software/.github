## About

Sidereal Software is a software engineering company. We take our name from sidereal time, the clock astronomers keep by the stars rather than the sun, and we try to build software with the same qualities: precise, dependable, and built for the long run.

Sidereal was founded by Dan Avner, who has spent more than a decade writing software for telescopes and spacecraft.
